Features

Everything branches. Everything is measured.

AI work branches on an infinite canvas instead of piling up in one endless chat. Each branch carries only its own context — so no agent ever drags the whole conversation behind it.

The Meter

A live savings dashboard, per canvas.

FLOWCODE measures how much context you saved versus running the same work as one linear session — both token volume and dollars, cache-aware.

Built to orchestrate, not to chat.

Per-task model routing

Every task is classified — coding, planning, thinking, web, image, or general — and routed to the right model for the job, automatically.

PM fan-out

One goal decomposes into parallel specialist agents that never fight over context. Parent → child → worker, each with its own lane.

Local-first, any model

Anthropic, OpenAI, Gemini, Grok, Ollama, and local CLIs. Your keys, your machine, no lock-in.

Quality control

A judge scores every deliverable 1–4; builds are verified with typecheck and tests, then visually reviewed after launch.

Lineage replay

Unchanged re-runs cost 0 tokens. FLOWCODE replays the lineage from cache instead of paying for the same work twice.

Session import

Import Claude Code or Codex CLI transcripts and rebuild them as an optimized branching canvas — your history, restructured.
